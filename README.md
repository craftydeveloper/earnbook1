# WeatherNow

A lightweight weather dashboard for searching a location and checking current conditions plus the 5-day forecast.

## Run
Open `index.html` in a modern browser. No install or API key is needed. Forecast and geocoding data come from Open-Meteo.

## Privacy
Searches go directly to Open-Meteo; this app does not create an account or store personal data. The last searched location is saved in this browser.
